## Sections
1. **Hero** — ชื่อ, ตำแหน่ง, ประโยคเดียวที่บอกจุดแข็ง, ปุ่ม [ดูผลงาน] [ติดต่อ], รูปโปรไฟล์
2. **About** — ย่อหน้าสั้น + ตัวเลขเด่น 3 ตัว
3. **Projects** — การ์ด 3–6 ใบ (รูป, ชื่อ, stack, Demo/GitHub)
4. **Skills + Experience** — กลุ่มทักษะ + timeline แนวตั้ง
5. **Contact** — อีเมล, LinkedIn, GitHub, ดาวน์โหลด Resume
